# Boochelorette 👻

A spooky-cute, black-on-black bachelorette landing page built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Publish on GitLab Pages

1. Create a GitLab project and push these files to its default branch.
2. GitLab will run `.gitlab-ci.yml`, build the app, and publish the `public/` artifact.
3. Open **Deploy → Pages** in your GitLab project to find the live URL.
